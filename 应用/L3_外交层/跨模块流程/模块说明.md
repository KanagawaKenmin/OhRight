# 跨模块协调

## 模块职责

连接用户动作、资料事务、排程与恢复。所属层级：L3。

## 文件导航

| 文件 | 职责 | 何时读取 |
|---|---|---|
| [应用状态.swift](应用状态.swift) | AppModel，唯一可观察快照与显式提交 | 修改对应行为时 |
| [界面测试场景.swift](界面测试场景.swift) | Debug + --uitest 的功能场景前置记录，经业务校验后写入隔离库 | UI 免费额度优化时 |
| [事项操作协调.swift](事项操作协调.swift) | 记录/计划用例的调用、保存与重排 | 修改对应行为时 |
| [提醒协调.swift](提醒协调.swift) | 串行重排、版本核对、通知操作 | 修改对应行为时 |
| [资料恢复协调.swift](资料恢复协调.swift) | 文件访问、安全快照、整库替换和脱敏报告 | 修改对应行为时 |
| [首次通知引导.swift](首次通知引导.swift) | 首页前台授权、旧安装保留偏好及一次开启提示 | 通知首次体验时 |
| [快捷事项操作.swift](快捷事项操作.swift) | 星标、归档/删除撤销与后续编辑保护 | 首页操作时 |
| [记录修正协调.swift](记录修正协调.swift) | 历史修正与含图草稿清除的单次提交 | 编辑记录时 |

## 接口与流程

依赖领域、必要 L1/L2 与系统框架；跨模块协调只在本层。 对外能力见各文件头与类型/函数声明。当前只实现本地个人试用；云端相关协议另在文档约定，不建立网络占位实现。

保存由 AppModel 显式协调；规则值不可直接触碰数据库。通知由系统适配器提交，UI 不能以投递成功冒充已被用户看见。

## 依赖边界与验证

0.4.3 三项非录入 UI 用例使用既有内存隔离库的场景记录，减少重复编辑器/键盘准备；仅 Bootstrap 在 Debug 且 inMemory/--uitest 同时成立时装配。Release 不编译场景，无用户界面入口，不更改正式数据。双模式用例仍真实录入和横滑；四项 UI 及原 300 秒上限保留。

恢复先在后台完成容器/图片解码检查，确认后写入含图安全快照和新附件，再核对资料版本并提交数据库；失败回收本次新增文件，保留旧快照和旧文件。设备系统授权与本机引导标记不从备份覆盖。

0.3 新增偏好失败回滚、连续设置、重排重入、恢复失败和撤销保护用例；仅语法检查已执行，SDK/测试执行状态见[实施记录](../../../文档/体验改版实施_0.3.md)。
