# 提醒算法

## 模块职责

纯函数规则筛选、随机抽样、摘要与本地计划。所属层级：L1。

## 文件导航

| 文件 | 职责 | 何时读取 |
|---|---|---|
| [本地提醒计划器.swift](本地提醒计划器.swift) | 三日窗口、稳定保留、冷却与容量 | 修改对应行为时 |
| [可用时间抽样.swift](可用时间抽样.swift) | 真实分钟、免打扰、夏令时 | 修改对应行为时 |
| [种子随机源.swift](种子随机源.swift) | 可复现非加密随机 | 修改对应行为时 |
| [计划摘要生成.swift](计划摘要生成.swift) | 未来时刻的计划排序与简短正文 | 修改对应行为时 |

## 接口与流程

依赖 L0；不调用 L2/L3。 对外能力见各文件头与类型/函数声明。当前只实现本地个人试用；云端相关协议另在文档约定，不建立网络占位实现。

保存由 AppModel 显式协调；规则值不可直接触碰数据库。通知由系统适配器提交，UI 不能以投递成功冒充已被用户看见。

## 依赖边界与验证

转计划使用持久化失效事项标记撤销该事项的旧琐事/稍后请求，保留其他事项的有效队列；重排成功后清除标记。星标不改变候选池或随机权重。
