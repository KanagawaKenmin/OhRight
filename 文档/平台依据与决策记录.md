## 2. 当前有效决策

### ADR-001：原生个人试用

用户确认只先验证自己的使用效果。保留 SwiftUI、SwiftData 与本地通知；不因未来可能上架就先引入账号、商业化或服务器体系。

### ADR-002：不做自动闲暇识别

用户选择免打扰时间带之外随机或全天随机。使用本机规则与随机数，不请求位置、日历、健康或屏幕使用数据。

### ADR-003：本地洗牌与三日排程

原 0.1 的约 14 天窗口和续排提示被本版替换。用户接受启动应用，本地只补齐含今天的 3 个自然日；随机候选采用简单洗牌，取消复杂优先分、后台补排和维护通知。保留基本次数、冷却和取消正确性。

### ADR-004：免费 Apple ID 自签名

原默认付费会员 + TestFlight 路线已撤销。当前为云端仅编译设备 IPA，Windows 使用免费 Apple ID 签名安装。续签负担由试用维护说明覆盖，不将其自动升级成付费需求。

### ADR-005：云端模式预留，当前不可激活

提醒模式 local/cloud 与内容模式琐事/计划独立。现在只有 local 真正可用；未来云端接入完成后才开放切换，保留切回本地的路径。

### ADR-006：接口按实际接缝预留

排程与投递、资料交换、推送注册、会话与能力的契约集中到《云端接口与交接约定》。本地实现时只提取被用到的协议；未来协议不要求先写占位类、网络调用、数据库表或后台管理系统。

### ADR-007：个人资料仍须可靠

保留显式保存、稳定 UUID、单机版本号、备份和恢复。必要的本地可靠性不是公众上架基础设施，不因试用而故意丢弃。

### ADR-008：保留产品设计

琐事逐步完善、计划进度与固定摘要、流动/几何两种风格继续有效。默认通知显示简短内容，可关闭预览。四层职责、中文业务文件与分页导航继续使用。

### ADR-009：已授权本地个人版开发

用户在修订方案后明确要求实施 0.2。本地 App、测试和构建配置已写入，服务器和云端接口不在当前范围。源码验证状态与尚需人工接入的步骤单独记录，不能以语法解析替代编译和装机证据。

## 3. 需要后续实证的内容

- 用户 iPhone 实际 iOS 与云 Xcode 镜像组合。
- 未签名设备 IPA 经当前 Sideloadly 版本的免费账号签名安装。
- 同身份同有效 Bundle ID 覆盖续签是否保留资料。
- 本地通知在锁屏、终止 App 和重启后的实际行为。
- 32 条工程预算的系统回读，以及三日窗口是否适合个人习惯。

这些项目尚未完成实证；本地静态检查结果见《开发验证记录》，不伪报云构建或装机通过。
