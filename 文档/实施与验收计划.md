# 实施与验收计划

版本 0.2。更新：2026-10-15。用户已明确授权按本计划开发。本地源码、测试及构建配置已写入；**M0 的云构建、真实签名和手机验收仍未完成**。详见[开发验证记录](开发验证记录.md)。

## 1. 必须继承的决定

- “哦对了”是个人 iPhone 17 原生试用 App，仍保留琐事/计划双模式与原视觉方向。
- 用户没有 Mac，允许云端 macOS 编译；安装用免费 Apple ID 自签名，不要求开发者会员或 TestFlight。
- 默认本地提醒：按本地规则筛选和随机洗牌，再按免打扰外/全天随机安排琐事；计划固定摘要。
- 打开 App 补排被用户接受，本地窗口为含今天的 3 个自然日，不开发后台自动续排。
- 云端模式、资料同步、推送和公开用户分发只留接口与说明，不实现远端基础设施。
- 用户后续已明确授权实际开发；当前无需重新批准产品范围，云端实现仍暂缓。

先读[项目导航](../项目导航.md)、[总体方案](总体设计方案.md)、[当前进展](任务进展/任务进展_当前.md)，接接口时再读[云端接口约定](云端接口与交接约定.md)。

## 2. 里程碑与交付

| 阶段 | 主要工作 | 退出条件 |
|---|---|---|
| M0 自签名验证 | 最小 App、云端无签名构建、Windows 签名安装 | 免费账号在真机运行；本地通知可用；覆盖续签保留测试资料 |
| M1 本地资料 | 一句话、草稿、补充、计划、进度、状态 | 重启不丢资料，转计划保留历史 |
| M2 双模式体验 | 首页、详情、编辑、设置、流动/几何样式 | 核心路径可用，基本无障碍通过 |
| M3 本地提醒 | 策略装配、随机洗牌、短期排程、摘要与撤销 | 本地无业务网络依赖，三日补排与取消正确 |
| M4 资料与个人试用 | 备份恢复、搜索、错误处理、续签说明 | 可日用 IPA、外部备份与个人体验反馈 |

阶段按实际验证调整，不以公开商店交付标准扩大工期。M0 不通时可继续纯逻辑工作，但必须准确说明装机未验证。

## 3. M0 的执行顺序

1. 准备单 App target、本地通知测试入口和文本工程定义，使用稳定标识与版本号。
2. 云端先运行模拟器检查，再编译 iphoneos 设备包；确认平台不是 iOS Simulator。
3. 将完整设备 App 打包为未签名 IPA，附校验值、源码版本和工具链信息。
4. 用户在 Windows Sideloadly 中用免费 Apple ID 签名，USB 装到 iPhone；凭据不交给聊天或 CI。
5. 按系统提示信任和启用 Developer Mode，实际运行。
6. 建立两分钟后本地通知，验证锁屏和退出 App 后的行为；回读 32 条未来测试请求，随后撤销，避免集中提醒。
7. 录入测试便条，用相同 Apple ID、有效 Bundle ID 和同一 IPA 覆盖续签，检查资料是否保留。
8. 记录手机系统、云镜像、工具版本、最终签名标识、有效期及通过/失败项。

M0 不配置 ASC API key、分发证书、APNs、CloudKit、登录账号或发布流程。安装工具不兼容时按部署文档定位，不能悄悄换成付费路线。

## 4. 本地模块实现顺序

1. L0 事项、截止时间、模式与本地已使用的协议。
2. L1 本地仓库、草稿、显式保存与资料版本。
3. L2 记录、进度、生命周期；L3 页面与跨模块协调。
4. L1 规则筛选、洗牌、时间抽样；L2 本地排程。
5. L3 本地通知、权限、路由、稍后与队列差量协调。
6. 备份恢复、搜索、回收站与视觉完善。
7. 文档记录云端契约如何接入；只为本地代码真正需要的接缝创建协议，不实现所有未来协议占位类。

## 6. 本地提醒与模式验收

| 编号 | 场景 | 通过标准 |
|---|---|---|
| N01 | 跨午夜免打扰 | 生成时刻均在允许范围 |
| N02 | 全天随机 | 昼夜均可抽到，次数仍受控 |
| N03 | 无候选/无可用时间 | 零通知，无死循环 |
| N04 | 单条琐事 | 同事项冷却生效，不强行发满 |
| N05 | 同日两条 | 满足间隔与固定提醒避让 |
| N06 | 重复启动 | 有效排程不反复洗牌，无重复请求 |
| N07 | 不同日期摘要 | 按各自日期计算，无空计划通知 |
| N08 | 保存与排程交错 | 新资料版本不会被旧结果覆盖 |
| N09 | 重复稍后回调 | 幂等，完成后不重新排入 |
| N10 | 32 条预算满 | 准确显示未覆盖项，不静默丢失 |
| N11 | 提交途中失败 | 资料保留，下次启动修复 |
| N12 | 时区与夏令时 | 截止语义一致，摘要无重复 |
| N13 | 窗口耗尽再启动 | 只补未来三日，不补发过去提醒 |
| N14 | 旧通知点击 | 路由到最新内容状态 |
| N15 | 固定种子洗牌 | 可复现、候选不丢失/重复，不夹带评分逻辑 |
| N16 | 本地模式断网 | 创建、查看、规则排程无需业务网络 |
| N17 | 请求云端模式 | 返回不可用，保留本地设置与队列；不伪造联网成功 |

使用虚拟时钟和可注入随机源测试规则；不写只重复实现语句的测试。云端接口只核对文档契约，不测试不存在的服务。

## 8. 当前试用完成定义

- 用户明确授权开发之后，P0 功能实现并完成相关检查。
- 交付实际可由免费 Apple ID 签名安装的设备 IPA，附版本与校验信息。
- iPhone 17 实测核心记录/提醒闭环，以及一次保留资料的续签。
- 本地模式离线运行；设置不开放尚未实现的云端能力。
- 完成一次备份恢复；只有发生资料结构升级时才要求对应迁移演练。
- 接手文档明确未来接口的参数、调用位置、错误行为与模式交接顺序。
- 不要求付费会员、TestFlight、APNs、业务服务器、业务云账号或商店审核；云构建账号仅用于编译。
