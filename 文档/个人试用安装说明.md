# 个人试用安装说明

适用于 0.2 本地个人版，Windows + 免费 Apple ID。设备 IPA 已经云端生成并在本地核验；可以直接从第 2 节开始安装，第 1 节供后续代码更新时重新构建使用。

本轮文件：[未签名 IPA](../build/codemagic/OhRight-personal-unsigned.ipa)、[SHA-256](../build/codemagic/OhRight-personal-unsigned.ipa.sha256)、[设备包核验](../build/codemagic/设备包核验.json)。版本 0.2.0，最低 iOS 26.0，源提交 `61d0ce8`。原始构建日志与 xcresult 保存在 `build/codemagic/OhRight_1_artifacts/`。

## 1. 获得设备版 IPA

1. 把源码上传到自己的私有 Git 仓库，包含 `应用/`、`资源/`、`测试/`、`构建/`、`Package.swift`、`project.yml` 和 `codemagic.yaml`。
2. 登录 Codemagic，连接该仓库，扫描根目录配置。
3. 手动运行 `verify`。无需填 Apple 凭据；查看核心测试日志、模拟器测试结果与截图附件。
4. 验证成功后手动运行 `package-personal`。它也会先运行测试，成功后打包。
5. 下载 `OhRight-personal-unsigned.ipa`、对应 `.sha256`、`device-platform.txt`、`toolchain.txt` 和 `build-info.json`。
6. Windows 使用 `Get-FileHash -Algorithm SHA256` 核对 IPA 的哈希。产物必须是 iOS 设备包；模拟器 `.app` 不能安装到手机。

工作流固定 Xcode 26.0 系列，允许 26.0.1 等补丁更新；实际版本记录在 `build/toolchain.txt`。XcodeGen 固定 2.46.0 与完整源码提交。如果平台不再提供该系列，应在 `codemagic.yaml` 与 `构建/工具版本.env` 一起升级，重新跑验证，不只把一边改成 latest。

免费构建额度受平台账户条件限制，工作流仅手动触发；未启用自动付费或商店发布。

## 2. Windows 自签名

1. 从 [Sideloadly 官网](https://sideloadly.io/)获取 Windows 工具。2026-10-15 官网说明 Windows 需要网页版 iTunes 和 iCloud，并提供下载入口；按页面要求准备依赖，不使用 Microsoft Store 版。是否需要替换现有安装以工具实际提示为准。
2. USB 连接已解锁的 iPhone，按系统提示信任电脑。
3. 在工具中选设备、下载的 IPA 和自己的免费 Apple ID，自行完成验证。不要把密码发到聊天、源码或云构建设置。
4. 保留源 Bundle ID `app.ohright.personal`，记录工具最终生成的有效标识；后续续签保持同一账号与标识。
5. 按提示在 iPhone 信任开发者、启用 Developer Mode。签名后才能运行，未签名文件不能直接安装使用。

本流程尚需在用户实际 iPhone/iOS/工具组合上验证。官方说明免费账号配置通常约 7 天有效，需要续签。[Apple 账号限制](https://developer.apple.com/help/account/basics/about-your-developer-account)。

## 3. 第一次验证

- 打开应用，记一句琐事，关闭再打开，检查是否保留。
- 新建计划，设置截止，记一次进度、添加和勾选步骤。
- 更多 → 提醒与设置，启用提醒并保存，允许系统通知。
- 通知检查 → 两分钟测试。退出应用并锁屏，实际观察横幅/通知中心，点击检查跳转。
- 用一条实际事项提醒，在应用终止时点“稍后提醒”，完成系统身份验证，检查是否生成新请求；此路径由后台回调直接加载资料，需单独确认。
- 可运行 32 条容量检查：请求安排在远期后立即撤销，不会故意集中弹出；已有队列太多时检查会拒绝，以保护原提醒。
- 备份与恢复 → 导出 JSON，再做一次明确确认的恢复，检查事项与历史。
- 使用同一 IPA、同一 Apple ID 和有效标识覆盖续签，确认上述资料保留；不要先删除应用。

## 4. 日常试用

每 5–6 天检查并续签。没有代码更新时可重签同一个 IPA，不必每次重新云编译。打开 App 补排三日提醒不会延长签名有效期。

更新代码前先将 JSON 导出到“文件”。卸载、换签名身份、换有效 Bundle ID 前尤其需要外部备份。恢复前的自动快照可在备份页找回，但它和应用一起卸载。

系统专注、通知摘要和锁屏预览可影响呈现；排程报告显示“系统接受”不代表人已看见。遇到问题导出脱敏排程报告，附构建号和手机系统版本。
