# 构建编排回归

| 文件 | 职责 |
|---|---|
| [test_模拟器准备.py](test_模拟器准备.py) | 运行时匹配、专用设备、一次超时恢复、两次失败、拒绝操作其他设备 |
| [test_源码版本.py](test_源码版本.py) | 清单匹配、旧文件替换、漏文件、过期文件与 BOM/CRLF |
| [临时工作区.py](临时工作区.py) | build 下隔离目录，清理前核对范围 |

运行：`python3 -m unittest discover -s 测试/构建 -p 'test_*.py' -v`。使用框架要求的 `test_` 前缀，使 unittest 能发现中文文件名；系统命令均有替身，文件操作在隔离目录中实际执行，不表示真实模拟器已恢复。
