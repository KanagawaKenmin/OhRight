## 从源码到 iPhone

1. 将本目录源码放进自己的私有 Git 仓库，连接到 Codemagic。
2. 上传内层源码内容到仓库根目录后，在 Codemagic 选择 main 和 `package-personal`（OhRight - Personal unsigned IPA）。它自动执行完整验证，通过后生成设备版未签名 IPA，无需先另跑 verify。
3. 下载构建产物 `OhRight-personal-unsigned.ipa` 和 `.sha256`，按[自签名安装说明](文档/个人试用安装说明.md)在 Windows 安装。

`verify` 用于只验证；日常安装只需一次 package-personal，避免重复消耗免费额度。声音专用诊断入口已删除。工具链使用 Xcode 26.0 系列，允许 26.0.1 等补丁版，实际版本记录在 `build/toolchain.txt`。

云端不需要 Apple ID、开发者会员、ASC API key 或签名证书。运行只用本地通知，不启用 APNs、CloudKit 或业务服务器。免费 Apple ID 的实际验证由用户在本机工具完成。

## 本地提醒默认值

- 首次首页前台请求系统通知授权；新装同意后自动启用，拒绝仍可记录。旧安装保持原提醒开关，授权成功后可选择开启。
- 琐事每天最多一条；免打扰 23:00–09:00，可选择全天随机。
- 新建/补充后冷却 24 小时，同一条至少间隔 72 小时。
- 每日计划摘要 20:30；启动、回到前台和修改资料后补齐含今天的三个自然日。
- 通知静音显示；App 不再提供声音开关或请求声音权限。
- 云端保留能力契约，正常设置隐藏不可用选择。

## 工程与维护

- XcodeGen：`project.yml`，工程/Scheme `OhRight`，个人打包配置 `PersonalTrial`。
- 四层领域与模块入口：[项目导航](项目导航.md)。
- 独立规则测试：具备 Swift 6 的环境运行 `swift test`。
- macOS 构建顺序：`bash 构建/准备工程.sh` → `bash 构建/验证工程.sh` → `bash 构建/打包个人版.sh`。
- 未来云端契约：[云端接口与交接约定](文档/云端接口与交接约定.md)。

个人数据未内置演示或上传流程。UI 测试在 Debug 的 `--uitest` 参数下使用独立内存库，不触碰真实资料。

验证脚本按核心测试、模拟器编译、模拟器启动、iOS 单元/存储测试、UI 测试五阶段执行；每 30 秒输出进度，各阶段限时退出。模拟器采用无账号的本机临时签名并串行测试；设备 IPA 仍由个人打包脚本关闭签名。失败时保留阶段日志与尽力收集的模拟器诊断、崩溃报告。

开始验证前先核对版本、源码清单指纹及实际提交，避免旧/混合上传。模拟器按当前 SDK 匹配运行时并创建独立设备，启动超时后保留诊断、重启该设备并重试一次；两次失败仍停止构建。UI 阶段上限 300 秒，verify 平台上限 30 分钟，个人打包 45 分钟；主验证全局 25 分钟保护保留。限时是最长等待，成功会立即进入下一步。末尾保留首个具体错误、失败用例及原退出码；完整阶段结果在 `build/verification-result.json`。专用模拟器仅用于云端测试，不进入设备 IPA，不改变覆盖更新身份。
