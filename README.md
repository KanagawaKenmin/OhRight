# 哦对了 · 个人试用版

SwiftUI 原生 iPhone App，最低 iOS 26.0。琐事留下想法，计划记录下一步；本地随机提醒与每日摘要帮助你再次想起。

已写入源码：双模式首页、草稿、补充与进度、检查项、转计划、完成/暂停/归档、搜索、回收站、JSON 备份恢复、Markdown 导出、提醒设置与通知检查。

**当前交付为源码与构建流程；尚未完成 Xcode 编译、Swift 测试执行和真机验证，没有可安装 IPA。** Windows 环境已完成 Swift 语法解析；它不能替代类型检查或 iOS 编译。详见[验证记录](文档/开发验证记录.md)。

## 从源码到 iPhone

1. 将本目录源码放进自己的私有 Git 仓库，连接到 Codemagic。
2. 选择 `verify` 工作流，使用锁定的 Xcode 26.0 执行核心与模拟器测试。
3. 测试成功后选择 `package-personal`；该流程会重新验证并生成设备版未签名 IPA。
4. 下载构建产物 `OhRight-personal-unsigned.ipa` 和 `.sha256`，按[自签名安装说明](文档/个人试用安装说明.md)在 Windows 安装。

云端不需要 Apple ID、开发者会员、ASC API key 或签名证书。运行只用本地通知，不启用 APNs、CloudKit 或业务服务器。免费 Apple ID 的实际验证由用户在本机工具完成。

## 本地提醒默认值

- 首次开启需允许通知；初始总开关关闭，记录可直接使用。
- 琐事每天最多一条；免打扰 23:00–09:00，可选择全天随机。
- 新建/补充后冷却 24 小时，同一条至少间隔 72 小时。
- 每日计划摘要 20:30；启动、回到前台和修改资料后补齐含今天的三个自然日。
- “本地/云端”能力已留接口，云端当前不可用。

## 工程与维护

- XcodeGen：`project.yml`，工程/Scheme `OhRight`，个人打包配置 `PersonalTrial`。
- 四层领域与模块入口：[项目导航](项目导航.md)。
- 独立规则测试：具备 Swift 6 的环境运行 `swift test`。
- macOS 构建顺序：`bash 构建/准备工程.sh` → `bash 构建/验证工程.sh` → `bash 构建/打包个人版.sh`。
- 未来云端契约：[云端接口与交接约定](文档/云端接口与交接约定.md)。

个人数据未内置演示或上传流程。UI 测试在 Debug 的 `--uitest` 参数下使用独立内存库，不触碰真实资料。
